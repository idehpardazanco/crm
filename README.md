# CRM Ideh Pardazan

سیستم داخلی مدیریت ارتباط با مشتری، تماس‌ها، پیگیری‌ها، سفارش‌ها و ارسال پیامک.

---

## تکنولوژی‌های پروژه

Backend:

- Laravel 13
- PHP 8.3+
- MySQL
- Laravel Queue
- Laravel Scheduler
- Spatie Laravel Permission
- Nwidart Laravel Modules

Frontend:

- Vue 3
- Inertia.js
- Tailwind CSS
- Vite

سایر امکانات:

- Laravel Excel
- SMS API
- Activity Logging
- Excel Import / Export

---

# قابلیت‌های اصلی

سیستم شامل بخش‌های زیر است:

- ورود و خروج کاربران
- مدیریت کاربران
- نقش مدیر و کارمند
- مدیریت مخاطبین
- تخصیص مخاطب به کارمند
- ثبت تماس
- ثبت نتیجه تماس
- تغییر وضعیت مخاطب
- ثبت پیگیری
- یادآوری پیگیری
- Scheduler پیگیری‌ها
- مدیریت قالب‌های پیامک
- ارسال SMS
- Queue ارسال SMS
- ثبت گزارش SMS
- جلوگیری از SMS تکراری
- مدیریت سفارش‌ها
- گزارش فعالیت‌ها
- داشبورد مدیر
- داشبورد کارمند
- گزارش عملکرد کارمندان
- نرخ تبدیل مخاطب به مشتری
- Import مخاطبین از Excel
- Export مخاطبین به Excel
- گزارش‌های پیشرفته
